## generate

默认入口的 `generate()` 是 Node.js 异步 API，会返回 Promise。

```ts twoslash title="generate-signature.ts"
import type { Encoding, GenerateResult, OutputFormat, QRCodeOptions } from '@ikenxuan/qrcode';

declare function generate<E extends Encoding = 'binary'>(
  options: QRCodeOptions,
  format: OutputFormat,
  encoding?: E,
): Promise<GenerateResult<E>>;
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `options` | `QRCodeOptions` | 二维码内容、尺寸、样式、背景、Logo 等配置。 |
| `format` | `OutputFormat` | `'svg'`、`'png'`、`'jpeg'`、`'webp'`。 |
| `encoding` | `'binary' \| 'base64'` | 输出编码，默认 `'binary'`。 |

## generateDy

生成抖音码。抖音码是抖音平台下发的圆形码，默认参数复刻官方作品分享码版式。

```ts twoslash title="generate-dy-signature.ts"
import type { DyCodeOptions, Encoding, GenerateResult, OutputFormat } from '@ikenxuan/qrcode';

declare function generateDy<E extends Encoding = 'binary'>(
  options: DyCodeOptions,
  format?: OutputFormat,
  encoding?: E,
): Promise<GenerateResult<E>>;

declare function generateDySvg(options: DyCodeOptions): Promise<string>;
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `options` | `DyCodeOptions` | 内容、尺寸、颜色、透明背景、模块形状与圆角、外框、中心图标和右上角图片。 |
| `format` | `OutputFormat` | 输出格式，支持 `'png'`、`'jpeg'`、`'webp'`、`'svg'`，默认 `'png'`。 |
| `encoding` | `'binary' \| 'base64'` | 输出编码，默认 `'binary'`。`generateDySvg` 直接返回字符串。 |

## 同步 API

同步 API 从默认入口导出，在当前线程执行，会阻塞调用线程。

```ts twoslash title="sync-signatures.ts"
import type { DyCodeOptions, Encoding, GenerateResult, OutputFormat, QRCodeOptions } from '@ikenxuan/qrcode';

declare function generateSync<E extends Encoding = 'binary'>(
  options: QRCodeOptions,
  format: OutputFormat,
  encoding?: E,
): GenerateResult<E>;

declare function generateSvgSync(options: QRCodeOptions): string;

declare function generateDySync<E extends Encoding = 'binary'>(
  options: DyCodeOptions,
  format?: OutputFormat,
  encoding?: E,
): GenerateResult<E>;

declare function generateDySvgSync(options: DyCodeOptions): string;

declare function scanSync(imageData: Uint8Array): string | null;
```

## 浏览器入口

浏览器和客户端组件使用 `@ikenxuan/qrcode/browser`，这个入口不会导入 Node.js 的 `worker_threads`。
它的同名方法同样返回 Promise，并通过浏览器 Web Worker 执行 WASM 计算。

```ts twoslash title="browser-import.ts"
import {
  generate,
  generateSvg,
  generateDy,
  generateDySvg,
  scan,
} from '@ikenxuan/qrcode/browser';

const png = await generate({ data: 'https://example.com' }, 'png');
const svg = await generateSvg({ data: 'https://example.com' });
const dyPng = await generateDy({ data: 'https://bing.com' }, 'png');
const dySvg = await generateDySvg({ data: 'https://bing.com' });
const text = await scan(png);

png;
svg;
dyPng;
text;
```

## QRCodeOptions

```ts twoslash title="options.ts"
import type { QRCodeOptions } from '@ikenxuan/qrcode';

const options: QRCodeOptions = {
  data: 'https://example.com',
  size: 300,
  margin: 12,
  shape: 'square',
};

options;
// ^?
```

| 字段 | 说明 |
| --- | --- |
| `data` | 要编码的 URL、文本或业务字符串。 |
| `size` | 二维码尺寸，单位像素，默认 `300`。 |
| `margin` | 二维码外边距，单位像素。 |
| `shape` | 整体形状，方形或圆形。 |
| `dotsOptions` | 点阵样式、颜色或渐变。 |
| `cornersSquareOptions` | 定位角外层方块样式。 |
| `cornersDotOptions` | 定位角内部点样式。 |
| `backgroundOptions` | 背景色、透明背景、背景渐变和圆角。 |
| `image` | Logo 图片二进制数据。 |
| `imageOptions` | Logo 尺寸、留白、圆角和背景点阵处理。 |

## DyCodeOptions

```ts twoslash title="dy-options.ts"
import type { DyCodeOptions } from '@ikenxuan/qrcode';

const options: DyCodeOptions = {
  data: 'https://bing.com',
  size: 400,
  darkColor: '#161823',
  lightColor: '#ffffff',
  moduleStyle: 'rounded',
};

options;
// ^?
```

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `data` | `string` | 无 | 要编码的内容，UTF-8 最多 38 字节。 |
| `size` | `number` | 自动 | 输出图片边长（像素）；提供后会反推 `scale`。 |
| `scale` | `number` | `1.833` | 每个设计单位对应的像素数。 |
| `margin` | `number` | `16` | 图片边距（像素）。 |
| `darkColor` | `CSSColor` | `#161823` | 数据环、定位环、外框和中心圆盘颜色。 |
| `lightColor` | `CSSColor` | `#ffffff` | 背景和中心图标颜色。 |
| `moduleStyle` | `DyModuleStyle` | `'rounded'` | 数据模块形状。 |
| `moduleRadius` | `number` | `1.2` | `rounded` 模式的圆角半径（设计单位）。 |
| `frame` | `boolean` | `true` | 是否绘制外圈装饰。 |
| `frameStyle` | `DyFrameStyle` | `'arcs'` | 外圈样式，取值 `arcs` / `ring` / `dashes` / `dots` / `ticks` / `double` / `segments` / `spark` / `orbit` / `gear`。 |
| `frameWidth` | `number` | `9` | 外圈径向宽度（设计单位），范围 `1` ~ `16`。 |
| `frameRadius` | `number` | `0` | 外圈端点圆角（设计单位）；圆环类样式在缺口处同样生效。 |
| `frameSpan` | `number` | `64` | `arcs` 样式每段弧的角度，范围 `4` ~ `120`。 |
| `frameCount` | `number` | `24` | `dashes` / `dots` / `ticks` 的元素数量，范围 `4` ~ `120`。 |
| `logo` | `boolean` | `true` | 是否绘制中心播放图标；提供 `centerImage` 时自动由图片替代。 |
| `centerImage` | `Uint8Array` | 无 | 覆盖整个中心圆盘的图片二进制，居中裁剪成圆形。 |
| `badge` | `boolean` | `true` | 是否启用右上角图片槽位。 |
| `badgeImage` | `Uint8Array` | 无 | 右上角圆形图片二进制；未提供时槽位留空。 |
| `formatCode` | `number` | `5` | 格式码 1..6，决定 RS 布局。 |
| `param` | `number` | `20` | 参数 0..63，低 4 位是掩码 id。 |
| `fieldXor` | `boolean` | `true` | 参数字段是否使用 `0x25412` 异或形式。 |

## ImageOptions

控制中心 Logo 的嵌入方式，需要与 `image`（Logo 二进制数据）配合使用。

```ts twoslash title="image-options.ts"
import type { QRCodeOptions } from '@ikenxuan/qrcode';

declare const logo: Uint8Array;

const options: QRCodeOptions = {
  data: 'https://example.com',
  image: logo,
  imageOptions: {
    imageSize: 0.22,
    margin: 8,
    round: 0.16,
    hideBackgroundDots: true,
  },
};

options.imageOptions;
// ^?
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `imageSize` | `number` | Logo 占二维码的比例，范围 `0.0 ~ 1.0`。建议 `≤ 0.25`，过大可能导致无法扫描。 |
| `margin` | `number` | Logo 周围的留白像素。 |
| `round` | `number` | Logo 圆角比例，范围 `0.0 ~ 0.5`；`0.5` 可将正方形 Logo 裁剪为圆形。只影响 Logo，不改变点阵挖空区域。 |
| `hideBackgroundDots` | `boolean` | 是否挖空 Logo 区域下方的点阵，避免图案叠加干扰。 |

<Callout type="info">
  `image` 接收图片**二进制数据**（`Uint8Array`），不是 URL 或路径。Node 端可用
  `readFileSync('logo.png')` 读取，浏览器端可用 `new Uint8Array(await blob.arrayBuffer())`。
  二维码有纠错能力，但 `imageSize` 过大仍可能无法识别，生成后建议用 `scan` 自检。
</Callout>

## 颜色格式

颜色字段接受常见 CSS 颜色字符串，包括 Hex、RGB/RGBA、HSL/HSLA、CSS Color 4 空格语法、OKLab、OKLCH 和常见命名颜色。
