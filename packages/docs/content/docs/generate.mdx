# 生成二维码

生成 API 由 `generate()` 与 `generateSvg()` 提供。默认入口中它们是 Node.js 异步方法；
浏览器使用 `@ikenxuan/qrcode/browser` 中的异步同名方法。
样式化和栅格渲染最终会进入
[`packages/wasm`](https://github.com/ikenxuan/qrcode/tree/main/packages/wasm) 中的 Rust WASM 实现，
底层生成能力来自 [`qr-code-styling`](https://crates.io/crates/qr-code-styling)。

## 基础生成

```ts twoslash title="generate.ts" lineNumbers
import { generate } from '@ikenxuan/qrcode';

const image = await generate({
  data: 'https://github.com/ikenxuan/qrcode',
  size: 320,
  margin: 12,
}, 'png');

image;
// ^?
```

Promise resolve 后默认得到 `Uint8Array`。如果第三个参数传入 `'base64'`，返回值会被推导为 `string`。

```ts twoslash title="base64.ts"
import { generate } from '@ikenxuan/qrcode';

const base64 = await generate({ data: 'https://example.com' }, 'png', 'base64');
//    ^?

const src = `data:image/png;base64,${base64}`;
```

## SVG

```ts twoslash title="svg.ts"
import { generateSvg } from '@ikenxuan/qrcode';

const svg = await generateSvg({
  data: 'https://example.com',
  dotsOptions: {
    dotType: 'classy-rounded',
    color: '#b7410e',
  },
});

svg;
// ^?
```

也可以使用 `await generate(options, 'svg')` 获取 SVG 的二进制数据。

## 样式化

```ts twoslash title="styled.ts" lineNumbers
import { generate } from '@ikenxuan/qrcode';

const image = await generate({
  data: 'https://github.com/ikenxuan/qrcode',
  size: 420,
  margin: 18,
  shape: 'circle',
  dotsOptions: {
    dotType: 'dots',
    gradient: {
      colorFrom: '#b7410e',
      colorTo: '#dea584',
    },
  },
  cornersSquareOptions: {
    cornerType: 'extra-rounded',
    color: '#5f2614',
  },
  cornersDotOptions: {
    cornerType: 'dot',
    color: '#5f2614',
  },
  backgroundOptions: {
    transparent: true,
  },
}, 'png');

image.byteLength;
//    ^?
```

## Logo 嵌入

`image` 接收 Logo 图片二进制，`imageOptions` 控制 Logo 比例、留白、圆角以及是否隐藏 Logo 区域下方点阵。

```ts twoslash title="logo.ts"
// @types: node
import { readFileSync, writeFileSync } from 'node:fs';
import { generate } from '@ikenxuan/qrcode';

const logo = readFileSync('logo.png');

const qrcode = await generate({
  data: 'https://example.com',
  size: 420,
  image: logo,
  imageOptions: {
    imageSize: 0.18,
    margin: 8,
    round: 0.16,
    hideBackgroundDots: true,
  },
}, 'png');

writeFileSync('qrcode.png', qrcode);
```

## 抖音码

`generateDy()` 生成抖音码（`BEF_CODE_TYPE_DY_CODE`），支持 PNG、WebP、JPEG 和 SVG。
它不复用标准 QR 的方阵布局，而是写入四条数据环、中心圆盘、三个定位圆环和外圈装饰；
默认参数复刻官方作品分享码的默认样式（格式码 5、参数 20、掩码 4）。

```ts twoslash title="generate-dy.ts"
import { generateDy, scan } from '@ikenxuan/qrcode';

const png = await generateDy({
  data: 'https://v.douyin.com/utbKgTJRmlI/',
  size: 400,
}, 'png');

// 生成的图片可以直接被 scan 解回原文
const text = await scan(png);
//    ^?
```

默认布局的消息容量是 40 字节，UTF-8 文本最多 **38 字节**（大约 12 个汉字）。
超出时会抛出 `文本过长` 错误。同步版本为
`generateDySync(options, format?, encoding?)`，`@ikenxuan/qrcode/browser` 入口也导出同名方法。

需要 SVG 字符串时使用 `generateDySvg()` / `generateDySvgSync()`；右上角图片会以
data URI 内嵌，方便直接写入 DOM 或继续编辑。

### 样式调整

颜色、透明背景、模块形状与圆角、外框、中心图标都不参与协议数据，可以自由调整：

```ts twoslash title="generate-dy-styled.ts"
import { generateDy } from '@ikenxuan/qrcode';

const png = await generateDy({
  data: 'https://v.douyin.com/utbKgTJRmlI/',
  size: 420,
  darkColor: '#1f3a5f',
  lightColor: '#f7f2e8',
  transparent: false,
  moduleStyle: 'rounded',
  moduleRadius: 1.2,
  frame: true,
  frameStyle: 'dashes',
  frameWidth: 8,
  frameRadius: 2,
  frameCount: 28,
  logo: true,
}, 'png');
```

`transparent: true` 会在 PNG / WebP / SVG 中保留 alpha 通道；JPEG 不支持透明，
透明区域会填充白色。`moduleRadius` 只对 `moduleStyle: 'rounded'` 生效。

外圈装饰全部位于数据环之外，不参与编码，因此可以自由更换。`frameStyle` 支持
`arcs`（官方四段弧）、`ring`（圆环）、`dashes`（断续弧段）、`dots`（圆点串）、
`ticks`（刻度线）、`double`（双层圆环）、`segments`（分段圆环）、`spark`（长短弧）、
`orbit`（双轨圆点）和 `gear`（齿轮环）。圆环类样式会在三个定位圆环和右上角图片处
自动断开，不会覆盖定位点。

| 字段 | 说明 |
| --- | --- |
| `frameWidth` | 外圈径向宽度（设计单位），默认 `9`，范围 `1` ~ `16`。 |
| `frameRadius` | 弧段端点圆角（设计单位），默认 `0`；圆环类样式在缺口处同样生效。 |
| `frameSpan` | `arcs` 每段弧的角度，默认 `64`，范围 `4` ~ `120`。 |
| `frameCount` | `dashes` / `dots` / `ticks` 的元素数量，默认 `24`，范围 `4` ~ `120`。 |

分段式外圈会自动避开 45° / 135° / 225° 的三个定位圆环和 315° 的右上角图片，
不会与它们重叠。

### 中心图片

`centerImage` 接收图片二进制，会按 cover 方式居中裁剪成圆形，覆盖整个中心圆盘并
替代播放图标（`logo` 不再绘制）。中心图片不占用有效数据位，生成结果仍可被
`scan` 识别：

```ts twoslash title="generate-dy-center.ts"
// @types: node
import { readFileSync } from 'node:fs';
import { generateDy } from '@ikenxuan/qrcode';

const avatar = readFileSync('avatar.png');

const png = await generateDy({
  data: 'https://v.douyin.com/utbKgTJRmlI/',
  centerImage: avatar,
}, 'png');
```

右上角 315° 方向是官方版式中的圆形图片槽位。它默认留空，传入 `badgeImage`
（图片二进制）后会自动居中裁剪并裁成圆形；该槽位不占用有效数据位。
`badgeRadius` 控制图片半径，默认 `21`（设计单位）：

```ts twoslash title="generate-dy-badge.ts"
// @types: node
import { readFileSync } from 'node:fs';
import { generateDy } from '@ikenxuan/qrcode';

const avatar = readFileSync('avatar.png');

const webp = await generateDy({
  data: 'https://v.douyin.com/utbKgTJRmlI/',
  badgeImage: avatar,
  badgeRadius: 18,
}, 'webp');
```

<Callout type="info">
  抖音 App 是否处理解码结果取决于载荷内容。测试时可使用
  `https://v.douyin.com/...` 形式的分享链接；普通 URL 可能被 App 拒绝。
</Callout>

## 浏览器下载

浏览器端使用 `@ikenxuan/qrcode/browser`，该入口不依赖 Node.js 内置模块，并通过 Web Worker 执行 WASM 计算。

```ts twoslash title="download.ts"
import { generate } from '@ikenxuan/qrcode/browser';

const bytes = await generate({ data: location.href }, 'webp');
const url = URL.createObjectURL(new Blob([bytes], { type: 'image/webp' }));

const link = document.createElement('a');
link.href = url;
link.download = 'qrcode.webp';
link.click();

URL.revokeObjectURL(url);
```
