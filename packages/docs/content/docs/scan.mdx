# 扫描二维码

`scan(imageData)` 接收图片二进制数据，支持 PNG、JPEG、WebP。默认入口中它是 Node.js 异步方法；
识别成功返回二维码内容，未识别到返回 `null`。
扫码实现位于
[`packages/wasm`](https://github.com/ikenxuan/qrcode/tree/main/packages/wasm)，底层二维码解码依赖
[`rxing`](https://crates.io/crates/rxing)。

## 抖音码

`scan` 同时支持抖音码（`BEF_CODE_TYPE_DY_CODE`）。
这类码没有标准 QR 的定位图案，而是由四条数据环、中心圆盘和定位圆环组成。
常规 QR 解码失败后，扫描器会自动尝试抖音码解码路径：

1. 通过中心暗盘、白色圆盘或三个定位圆环推导码心与尺度；
2. 对四条数据环做极坐标采样；
3. 搜索旋转角与遍历方向，读取格式/参数字段；
4. 解扰并做 Reed-Solomon 纠错，最后解析 QR 风格位流。

调用方式与普通扫码完全一致，不需要额外参数：

```ts twoslash title="scan-dy-code.ts"
// @types: node
import { readFileSync } from 'node:fs';
import { scan } from '@ikenxuan/qrcode';

const image = readFileSync('douyin-code.png');
const text = await scan(image); // 'https://v.douyin.com/...'
```

## 获取二维码位置

需要把识别结果标在原图上时，使用 `scanDetailed(imageData)`。它返回文本、
原图尺寸和位置信息：

```ts twoslash title="scan-detailed.ts"
// @types: node
import { readFileSync } from 'node:fs';
import { scanDetailed } from '@ikenxuan/qrcode';

const image = readFileSync('qrcode.png');
const result = await scanDetailed(image);
// result?.points：定位点（标准二维码为定位图案中心；抖音码为圆心或三个圆形标记中心）
// result?.circle：抖音码的圆心与半径
```

坐标均为原图像素坐标。同步版本为 `scanDetailedSync`，
`@ikenxuan/qrcode/browser` 入口也导出同名方法。

## 扫描生成结果

```ts twoslash title="scan-generated.ts"
import { generate, scan } from '@ikenxuan/qrcode';

const image = await generate({ data: 'hello qrcode' }, 'png');
const text = await scan(image);
//     ^?
```

## Node.js 扫描本地图片

```ts twoslash title="scan-file.ts"
// @types: node
import { readFileSync } from 'node:fs';
import { scan } from '@ikenxuan/qrcode';

const image = readFileSync('qrcode.png');
const text = await scan(image);

if (text) {
  console.log('decoded:', text);
}
```

## 浏览器上传扫码

```ts twoslash title="scan-upload.ts"
import { scan } from '@ikenxuan/qrcode/browser';

export async function scanFile(file: File): Promise<string | null> {
  const bytes = new Uint8Array(await file.arrayBuffer());
  return await scan(bytes);
}
```

## 识别建议

<Accordions type="single">
  <Accordion title="透明背景能识别吗？">
    可以。透明背景 PNG / WebP 会自动合成白底再参与识别。
  </Accordion>
  <Accordion title="大图里的小二维码能识别吗？">
    扫码逻辑包含多区域分块扫描，但更清晰、更高对比度的原图仍然更稳。
  </Accordion>
  <Accordion title="识别失败会抛异常吗？">
    一般不会。没有二维码、图片损坏或无效数据会返回 `null`。
  </Accordion>
</Accordions>
