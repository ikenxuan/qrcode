# 快速开始

`@ikenxuan/qrcode` 用来生成和识别二维码。核心由 Rust 编译成 WebAssembly，WASM 已经内联进包里，import 即可使用，不需要手动加载 `.wasm` 文件或初始化。

## Node.js 异步调用

```ts twoslash title="quick-start.ts"
import { generate, generateSvg, generateDy, scan } from '@ikenxuan/qrcode';

const png = await generate({ data: 'https://example.com' }, 'png');
//     ^?

const svg = await generateSvg({ data: 'https://example.com' });
//     ^?

const dyPng = await generateDy({ data: 'https://bing.com' });
//     ^?

const text = await scan(png);
//     ^?
```

默认入口面向 Node.js。`generate()`、`generateSvg()`、`generateDy()` 和 `scan()` 都返回 Promise，计算通过 `worker_threads` 放到后台线程。

## 浏览器调用

```ts twoslash title="browser.ts"
import { generate, generateSvg, generateDy, scan } from '@ikenxuan/qrcode/browser';

const png = await generate({ data: location.href }, 'png');
const svg = await generateSvg({ data: location.href });
const dyPng = await generateDy({ data: 'https://bing.com' });
const text = await scan(png);
```

浏览器、React Client Component、Vue SFC 等客户端环境使用 `@ikenxuan/qrcode/browser`。这个入口不依赖 Node.js 内置模块，计算通过浏览器 Web Worker 执行。

## 实现

底层是 [`packages/wasm`](https://github.com/ikenxuan/qrcode/tree/main/packages/wasm) 里的 Rust crate。生成基于 [`qr-code-styling`](https://crates.io/crates/qr-code-styling)，识别基于 [`rxing`](https://crates.io/crates/rxing)。

## 环境支持

| 环境 | 说明 |
| --- | --- |
| Node.js | 支持异步 API 和同步 API。 |
| 浏览器 | 使用 `@ikenxuan/qrcode/browser`，可生成、下载和扫描。 |
| ESM | 包为 ESM，适用于现代 Next.js、Vite 和 Node.js ESM 项目。 |
